蠕虫病毒又来喽！我们可以通过配置 minimumReleaseAge 来进行简单的防护。一般配置个一个星期就可以了。

你用 pnpm 可以在 `pnpm-workspace.yaml` 中配置

```yaml
minimumReleaseAge: 10080
```

如果你是用 npm，可以在 `.npmrc` 中配置

```ini
min-release-age=7d
```

::note
注意：在 npm 中默认单位是天，pnpm 中默认单位是分钟
::
