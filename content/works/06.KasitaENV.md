# Kasita ENV

<a href="https://kermanx.github.io/reactive-vscode/" target="__blank"><img style="width: 200px;" src="https://img.shields.io/badge/made_with-reactive--vscode-%23007ACC?style=flat&labelColor=%23229863"  alt="Made with reactive-vscode" /></a>

一个VS Code扩展，用于在 `.env` 文件中隐藏/显示环境变量的值，在处理敏感信息时提升隐私性和可读性。

<p align="center">
<img alt="kasita-env-example" src="https://raw.githubusercontent.com/Whbbit1999/kasita-env/refs/heads/main/res/kasita-env.png" width=75%>
</p>

## 功能特性

- **切换所有值**：通过单个命令快速隐藏或显示打开的 `.env` 文件中的所有环境变量值。
- **切换行值**：逐行切换特定环境变量值的可见性。
- **CodeLens 集成**：直接在编辑器中使用 CodeLens 无缝切换单行值的可见性。
- **支持多种 .env 文件**：识别并支持 `.env`、`.env.local`、`.env.development`、`.env.production` 及其他类似的环境变量文件。

## 安装

1.  打开 VS Code。
2.  进入扩展视图（快捷键 `Ctrl+Shift+X` 或 `Cmd+Shift+X`）。
3.  搜索 "Kasita ENV"。
4.  点击“安装”。

## 使用方法

安装完成后，当你打开 `.env` 文件时，该扩展会自动激活。

### 命令

你可以通过命令面板（快捷键 `Ctrl+Shift+P` 或 `Cmd+Shift+P`）使用以下命令：

| 命令                      | 标题                  | 描述                                           |
| :------------------------ | :-------------------- | :--------------------------------------------- |
| `kasita-env.toggleValues` | 切换所有 ENV 值可见性 | 隐藏或显示当前 `.env` 文件中的所有环境变量值。 |
| `kasita-env.toggleLine`   | 切换行值可见性        | 隐藏或显示当前行的环境变量值。                 |

### CodeLens

对于每一行，环境变量上方都会显示一个 CodeLens。点击该 CodeLens 即可切换对应行值的可见性。
